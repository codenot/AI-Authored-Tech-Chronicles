读表规则
  1. 第 1 列是产品世代；第 2 列是这一代共用的微架构 / 工艺 / 插槽 / 内存 / I/O。
  2. 第 3–5 列按档次分行：旗舰、高性能、主流、入门（若该代无独立入门线则省略）。每一档只列该档最高型号。
  3. Geekbench 能抓到哪个大版本就列哪个：GB2（2008-08）→ GB3（2013-02）→ GB4（2016-11）→ GB5（2019-09）→ GB6（2023-02）→ GB7（2026-07）。版本之间不可换算。
  4. 分数来源：GB7 优先 Browser 官方榜；没有官方榜的型号用 CPU-Monkey / Notebookcheck / Geekbench 博客 PC Performance 等。编造分数不会出现，找不到就留空。
  5. Geekbench 2 只公布 综合分（相对 Power Mac G5 1.6 GHz = 1000），没有单核/多核拆分，不可与 GB3 之后的分核分数换算。
  6. Cinebench R23 于 2020-11 发布。笔记本受功耗墙影响；服务器超高核心数 Geekbench 线程扩展有限。
