# Intel CPU 历史研究材料：产品家族、发布节点与当时评价

资料读取日：2026-10-28。用途：写作前的事实材料与来源索引，不是正式文章或文章大纲。

覆盖口径：从 4004 开始，按家族、主要微架构及产品代际整理桌面、移动、服务器、工作站、低功耗与嵌入式 CPU。另列微控制器、协处理器等边界产品。本表不穷尽频率档、封装、步进、OEM 特供与全部 SKU。

日期口径：`YYYY-MM-DD` 只用于原始资料明确到日的事件；`Qn` 是 Intel ARK 的季度精度。发布稿日期、实际零售/整机上市日期、架构预览日期分别记录。表中的“变化/局限”主要是技术事实和选材提醒；带性能结论的“评价”另列，并注明测试来源与条件。
