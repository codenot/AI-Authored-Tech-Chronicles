读表规则
  1. 移动端代表须有中国大陆销售的主流品牌笔记本或一体机搭载依据；包括历史国行机型，不把海外配置当作国行配置。同系列不同 CPU 后缀分别核实，型号下列整机与来源，可按品牌或整机名称搜索；无法核实的早期世代保留介绍并注明缺口。
  2. 桌面只选普通家用装机平台、曾可单独购买的 CPU，盒装与散片均计入；不含 Threadripper / Threadripper PRO、服务器、笔记本焊接芯片、魔改转接型号，以及尚未核实独立单卖的 OEM 型号。OEM 首发不等于永远不能单买，有后续盒装或散片销售记录的型号可以保留。历史型号不表示今天仍有全新零售库存。
  3. 早期产品按家族合并，Ryzen 桌面 CPU 与 G 系列 APU 分列；系列年份不是每个型号的精确上市日期；表内 2025、2026 年 Ryzen 9000 X3D 新品按发布批次单列，仍属 Zen 5。第 1 列是产品世代；第 2 列是这一代共用的微架构 / 工艺 / 插槽 / 内存 / I/O。
  4. 日期优先采用 AMD 产品页的 Launch Date，已核实日期至少精确到月；仅能核实公告时标注“公布”。OEM 与零售时间不同时分别标明。早期档案未能确认月份的型号明确标注“发布月份未核实”，不以系列日期或授权协议日期代替。
  5. 日期下方列中国大陆发布价格，以人民币（¥）表示，并区分国行建议零售价、首发标价与预售标价。仅查到厂商公布的首发活动价时单独注明；有预售定金抵扣时优先列优惠前标价。发布日期沿用各型号的原始记录，国行晚于全球上市的价格另注国行时间；OEM 与零售分批上市时价格对应各自日期。中国首发价未核实的条目明确标注，不以美元换算、现价、后续降价或整机售价代替。数字价格可点击查看来源。
  6. 第 3–5 列直接列出代表型号、规格和跑分，不附加性能档次标签。Ryzen 按 3 / 5 / 7 / 9 产品线选取代表；早期 CPU 按产品家族、服务器按核心规模与用途选取代表。
  7. 每个型号固定显示 GB5、GB6、R23 三项，每项分别列单核和多核。不同软件及大版本分数不可换算；未找到可核验记录时显示“—”及说明，缺失的单核或多核也分别保留“—”。
  8. 型号与日期核对（2026-10-10）：AMD 产品规格表、EPYC 9004 型号表。移动端国行代表重选于 2026-10-22；原有跑分核对于 2026-10-16，新增型号的已核实记录补充于 2026-10-22。
  9. 分数来源：CPU-Monkey 的型号 / 对比 / 测试页、Notebookcheck 数据库与 StorageReview 实测。数字链接对应具体来源；Notebookcheck 取数据库中位数，CPU-Monkey 使用其收录值，均作为参考，不表示同一测试平台或默认功耗的严格横向比较。
  10. Cinebench R23 于 2020-11 发布。早于测试软件上市不代表后来不能测试；早期型号仍以是否有可核验记录为准。笔记本结果受整机散热与功耗设置影响；服务器注明单路 / 多路与 SMT 等条件，不按核心数线性外推。
  11. 家用桌面逐代评价：先区分架构大改、小幅优化、扩核与同代扩展，再看实际收益；大改不等于性能必然大涨。每项实测注明对比型号、测试软件或游戏集与时间，不把官方 IPC、核心数、单项最高值或不同来源 GB 分数当作统一“整体提升”。耗时缩短与吞吐提高分别表述；跨档、跨代、内存与功耗设置不同的对照明确说明。未核实可靠数据的早期条目标明缺口，不推算百分比。移动与服务器继续使用各自的平台口径，不套用桌面结论。

  • 家用桌面选样（2026-10-22）：依据 AMD Threadripper 平台资料排除 HEDT / 工作站型号。4700G 散片商品记录、4300G 独立零售记录与 5300G 盒装销售记录用于确认单卖形式；其中日本零售商记录 5300G 于 2024-11 开始销售，不据此推定全球或中国首发日期。4600G 的 2022-04 零售批次依据 AMD 原始公告。海外商品价格不用于填充人民币首发价格。

  • Geekbench 5 / 6：CPU-Monkey 型号与测试页、Notebookcheck 数据库；表内数字各自附来源，资料读取于 2026-10-16。未收录或未能复核的分数保留“—”。
